# План практик по теорверу (y2025)

Преподавательский конспект из файла «Теорвер План y2025». Это не студенческий учебник: здесь ход пары, тайминг самостоятельных, пометки себе и скриншоты с доски.

Домашки, контрольные и лабы на сайт пока не переносились — на страницах практик остались только отсылки к файлам вроде `HW1_y2023.pdf`. Исходники ДЗ и КР лежат в репозитории `teorver-other`.

## Как открыть

Нужен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
mkdocs serve
```

Сайт: [https://pavladog.github.io/teorver-site/](https://pavladog.github.io/teorver-site/). Локально: [http://127.0.0.1:8000](http://127.0.0.1:8000).

Исходный Word-файл не менялся: `../teorver-other/Теорвер План y2025.docx`.
